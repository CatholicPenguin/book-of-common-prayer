# 2025 Proposed Book of Common Prayer
The *2025 Proposed Book of Common Prayer* is a revision of the 1928 Book of Common Prayer. It is edited for Orthodox use within the Antiochian Western Rite Vicariate.

# Sources
The *2025 Proposed Book of Common Prayer* starts with the 1928 Book of Common Prayer (1928 BCP), revising only when necessary or truly expedient. When revising, the closest liturgical relative to the 1928 BCP is used. This prevents novel and discordant accretions from entering (a phenomenon far too common in recent years). Therefore, if something needs to be changed, we look within the Prayer Book Tradition for a suitable change. If the solution cannot be found within the Prayer Book Tradition, the Sarum Rite is then consulted. For the Mass, following Vicariate practice, the English Missal is used (specifically the 1933 edition of the lay missal). For the Daily Office, the Breviarium Monasticum is used. This has allowed this liturgical revision to be conservative and to feature no personally written or collated or preferred prayers, cycles, or features. Only in a few places has any 'creative' work been necessary for this revision, and it is noted and defended in the comments of the .tex files.
